# PAKKA implementation plan

1. Next.js + TypeScript; SQLite via Node 24 native node:sqlite (exact integer paise). Real opaque server-side sessions.
2. Shared debt state machine: invitations, acceptance, bilateral amendments, payment confirmation/dispute, append-only history.
3. Responsive navy/purple dashboard, exact simple interest/EMI calculations, deterministic reminders.
4. Official Hindsight REST integration, per-agreement banks, verified-event outbox, evidence and memory comparison.
5. Finance, authorization and workflow tests; typecheck, lint, production build; walkthrough and honest integration proof.

Local only. No deployment, publishing or paid actions. Native SQLite avoids Prisma adapter overhead for this lean demo.
